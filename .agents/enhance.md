## 손익 계산

- 손익 = 별의 값(기댓값 계산기 `starSteps` 의 가장 싼 비용, 그 시도의 이벤트 · 스타캐치 그대로, MVP · PC방은 API 에 없어 사용자가 고른 값 `enhance:discount` 을 모든 시도에 — 기댓값 계산기와 같은 규칙: 16→17 시도까지 · 둘을 더한 뒤 이벤트 할인을 곱함, 2026-11-12 사용자 요청) 기준: 성공 + 얻은 별 − 비용 / 실패 − 비용 / 파괴 − 비용 − 노작 − 잃은 별(12성까지) 또는 확정 복구 값. 가장 싼 선택으로 한 시도는 평균 0(테스트로 고정). 운 지수 = 손익 합의 정규 근사 상위 %(30건부터, Claude 가 정한 방식).
- 구간별 확률 탭은 2026-11-12 사용자 요청으로 삭제. `stats.ts` 의 `odds` · `luckTop`(운 지수)은 계산만 남아 있고 화면에는 안 나옴 — 다시 쓸 일이 없으면 지워도 됨.
